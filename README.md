# Неоновый Куб — веб-приложение (PWA)

Готовая папка для загрузки на хостинг. После загрузки игру можно установить на iPhone и Android как приложение: с иконкой, на весь экран и с работой без интернета.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | Сама игра и окно с инструкцией по установке |
| `manifest.webmanifest` | Название, иконки и цвета приложения для Android и Chrome |
| `sw.js` | Офлайн-режим: игра запускается без интернета после первого открытия |
| `icon-*.png`, `apple-touch-icon.png`, `maskable-512.png`, `favicon-32.png` | Иконки для iPhone, Android и вкладки браузера |
| `screenshot-*.png` | Скриншоты, которые Android показывает в окне установки |

Все файлы лежат в одной папке, без вложенных, поэтому их можно загрузить разом через «Выбрать все».

## Как загрузить

Главное условие: сайт должен открываться по **https://**. Без https установка и офлайн-режим не работают. Все варианты ниже бесплатные и дают https сами.

**Netlify Drop (проще всего, 1 минута)**
1. Открой app.netlify.com/drop.
2. Перетащи туда папку `neon-cube-pwa` (на телефоне — нажми «browse to upload» и выбери все файлы).
3. Получишь ссылку вида `https://что-то.netlify.app` — это и есть игра.

**GitHub Pages**
1. Создай репозиторий и загрузи в него содержимое папки (файл `index.html` должен лежать в корне).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту игра будет по адресу `https://имя.github.io/репозиторий/`.

**Обычный хостинг (через FTP или панель управления)**
Загрузи содержимое папки в `public_html` (или в любую подпапку) и включи SSL-сертификат в панели. Все пути в игре относительные, так что подпапка тоже подойдёт.

## Как установить на телефон

Открой ссылку на сайт. Если игра открыта в браузере, а не как приложение, при каждом входе появится окно с пошаговой инструкцией для iPhone и Android с анимированными подсказками. Ещё его можно открыть кнопкой «Установить на телефон» в главном меню.

- **iPhone:** Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
- **Android:** Chrome → ⋮ → «Установить приложение» → «Установить». Если Chrome это поддерживает, в окне появится кнопка «Установить в один тап».

Когда игра запущена с иконки, окно с инструкцией не появляется.

## Как обновить игру

1. Замени `index.html` новой версией.
2. В файле `sw.js` поменяй строку `const VERSION = 'neon-cube-v1';` на `v2`, `v3` и так далее.

Тогда у всех игроков подтянется свежая версия при следующем запуске с интернетом.

## Проверка

Открой сайт в Chrome на компьютере → F12 → вкладка **Application** → **Manifest**. Там должны быть видны иконки, а ошибок быть не должно. Вкладка **Service workers** должна показывать статус «activated».
